# Seguridad

## Versiones soportadas

La rama `main` y la versión `1.x` reciben correcciones de seguridad.

## Reportar una vulnerabilidad

No abras un issue público con detalles explotables. Cuando el repositorio tenga
un remoto en GitHub, utiliza **Security → Report a vulnerability** para crear un
aviso privado. Incluye el impacto, los pasos mínimos para reproducirlo y una
forma segura de contacto.

No incluyas credenciales, tokens de reconexión ni datos de jugadores reales en
el reporte. Se confirmará la recepción y se coordinará la publicación de la
corrección antes de divulgar los detalles.
